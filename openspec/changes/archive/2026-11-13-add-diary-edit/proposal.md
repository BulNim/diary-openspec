# Proposal

## Why

지금은 한 번 저장한 기록을 고칠 방법이 없어서, 오타 하나를 바로잡으려 해도 새 기록을 다시 써야 하고 잘못된 기록이 그대로 남는다. 첫 변경(`add-diary-write`)으로 작성·목록 흐름이 갖춰졌으니, 이미 쓴 기록의 내용을 고칠 수 있게 한다.

## What Changes

- 목록의 각 기록 옆에 "수정" 버튼을 둔다.
- "수정"을 누르면 그 기록 줄이 현재 내용이 채워진 입력칸과 [저장]·[취소] 버튼으로 바뀐다. 한 번에 한 기록만 수정할 수 있다.
- Enter 또는 [저장]으로 수정 내용을 저장하고, Esc 또는 [취소]로 바뀐 내용을 버리고 원래 표시로 돌아간다.
- 수정해도 기록의 원래 날짜·시각과 목록 순서는 바뀌지 않는다. 내용만 바뀐다.
- 비어 있거나 공백만 있는 내용으로 저장하려 하면 저장하지 않고 "내용을 입력해 주세요." 경고를 보여준다(작성 때와 같은 규칙).
- 수정한 내용은 새로고침 후에도 유지된다.
- 범위 밖: 기록 삭제, 날짜·시각 수정, 수정 이력·"수정됨" 표시, 여러 기록 동시 수정.

## Capabilities

### New Capabilities
- 없음

### Modified Capabilities
- `diary-entries`: 저장된 기록의 내용을 목록에서 직접 수정하는 요구사항을 추가한다. 기존 작성·목록 요구사항의 동작은 바뀌지 않는다.

## Impact

- 코드: `index.html`(필요 시 마크업 보완), `app.js`(기록 수정 저장소 함수, 목록 항목의 보기/수정 상태 그리기, 수정 이벤트 처리).
- 저장 형식: 기존 `one-line-diary.entries` 키와 기록 구조를 그대로 쓴다. 기존 데이터 이전은 필요 없다.
- 의존성 변화 없음.
