# Proposal

## Why

하루를 길게 쓰지 않고 한 줄로 가볍게 남길 수 있는 다이어리가 필요하다. 지금 프로젝트에는 앱 코드가 전혀 없으므로, 첫 변경으로 "쓰고 → 보는" 최소 흐름부터 만든다.

## What Changes

- 화면 상단에 오늘 날짜를 `YYYY-MM-DD` 형식(예: `2026-12-31`)으로 자동 표시한다.
- 한 줄 입력칸과 저장 버튼을 둔다. Enter 키로도 저장할 수 있다.
- 저장할 때 내용과 함께 작성 날짜·시각을 기록한다. 같은 날 여러 번 작성할 수 있으며, 각 기록은 별개로 남는다.
- 빈 입력이나 공백만 있는 입력은 저장하지 않고, 입력칸 아래에 경고 메시지를 보여준다.
- 기록은 브라우저 `localStorage`에 보관되어 새로고침 후에도 유지된다.
- 저장된 기록을 최신순 목록으로 보여준다. 목록은 5개 높이까지 보이고, 그보다 많으면 목록 영역 안에서 스크롤한다.
- 범위 밖: 기록 수정·삭제, 검색, 날짜별 필터, 서버 저장·동기화는 이번 변경에 포함하지 않는다.

## Capabilities

### New Capabilities
- `diary-entries`: 한 줄 다이어리 기록의 작성(입력·검증·저장)과 저장된 기록의 목록 표시, 그리고 오늘 날짜 표시를 다룬다.

### Modified Capabilities
- 없음

## Impact

- 새 파일: 정적 웹 페이지(`index.html`)와 Vanilla JS 스크립트. 빌드 도구 없이 브라우저에서 바로 연다.
- 의존성: Tailwind CSS(CDN 스크립트로 로드). 그 밖의 라이브러리는 쓰지 않는다.
- 저장소: 브라우저 `localStorage` 키 하나를 사용한다. 기기·브라우저 사이 동기화는 없다.
