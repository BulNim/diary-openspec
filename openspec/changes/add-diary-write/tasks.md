## 3. 저장소 접근

- [ ] 3.1 `one-line-diary.entries` 키 읽기 함수 구현: 값이 없거나 JSON 파싱 실패·배열 아님·접근 예외면 빈 배열 반환. 콘솔에서 해당 키에 `"{망가짐"`을 넣고 새로고침해 화면이 오류 없이 빈 목록으로 열리는지 확인
- [ ] 3.2 기록 추가 함수 구현: `{ id, date, time, text, createdAt }`을 배열에 덧붙여 저장, 쓰기 실패 시 실패를 호출자에게 알림. 콘솔에서 두 번 호출한 뒤 `localStorage` 값에 기록 2개가 있는지 확인

## 4. 작성 흐름

- [ ] 4.1 `<form>` `submit` 처리: `preventDefault`, `trim` 후 빈 문자열이면 저장하지 않고 입력칸 포커스 + 경고 메시지 "내용을 입력해 주세요." 표시. 빈칸·공백만 입력하고 저장 버튼과 Enter를 각각 눌러 기록이 늘지 않고 경고 메시지가 보이는지 확인
- [ ] 4.2 유효한 입력이면 저장 시점의 날짜·시각과 함께 저장하고 입력칸 비우기, 저장 실패 시 입력 유지. 버튼과 Enter로 각각 저장해 `localStorage`에 날짜·시각·내용이 맞게 들어가고 입력칸이 비는지 확인
- [ ] 4.3 같은 날 두 번 저장해 기록 2개가 모두 남는지 확인
- [ ] 4.4 입력칸 `input` 이벤트와 저장 성공 시 경고 메시지 숨기기. 경고가 보이는 상태에서 글자를 입력하면 경고가 사라지는지 확인

## 5. 목록 표시
